# 簡単な構成管理のコードを作成
gitを入れるだけのコードを作成

## tasks/main.ymlを編集
```
---
# tasks file for test_role
- name: Install github
  ansible.builtin.apt:
    name:
      -git
    state: present
    update_cache: true
  became: true
```

## gitをインストールするtaskをローカルで実行
ルートディレクトリに移動してテストを実行

```
cd ~/molecule-test
```
```
ansible-playbook test_role/tests/test.yml --check --ask-become-pass
```
