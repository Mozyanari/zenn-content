# ansibleのインストール
参考文献：
https://docs.ansible.com/ansible/latest/installation_guide/intro_installation.html#pip-install
## pythonのバージョンの確認
```
python3 -m pip -V
```
```
pip 22.0.2 from /usr/lib/python3/dist-packages/pip (python 3.10)
```
なかったら、pythonをインストール

## ansibleのインストール
```
python3 -m pip install --user ansible
```
